# draw.io / diagrams.net import files

This directory contains architecture diagrams in formats directly importable into draw.io (diagrams.net).

## Files

- `system_architecture.drawio.csv`  
  Import via **File → Import From → Device**, then select the CSV file.

- `auth_flow.drawio.xml`  
  Import via **File → Import From → Device**, then select the XML file.

## Notes

- The CSV file uses draw.io CSV directives for shape styling, auto-layout, and edge generation.
- The XML file is a native `mxfile` document and can also be opened directly in diagrams.net.
